# Changelog

## 1.0.0

- Expand newly added files to the available width in split pull request diffs.
- Support GitHub's classic and React table diff renderers.
- Preserve split layout for modified and deleted files.
- Handle late-loaded diffs and in-page navigation.
- Keep line numbers, syntax highlighting, and review controls.
- Support GitHub.com and hosted `*.ghe.com` instances, with documented setup for
  self-hosted GitHub Enterprise domains.
